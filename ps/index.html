Description

Overview

The exchange quirks ontology (xqo) product specs (xm) module provides vocabulary to capture the instatiation templates of exchange-listed derivatives.

Why?

Neither FIBO nor FIX deal with analytical workflows like, in this case, universe selection.

How?

Where?

This ontology is part of xqo, (official github repository).

The project's canonical home is http://schema.ga-group.nl/xqo/ps/.
