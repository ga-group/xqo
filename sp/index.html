Description

Overview

The exchange quirks ontology (xqo) specific products (sp) module provides vocabulary to capture instatiations of exchange-listed derivatives.

Why?

Neither FIBO nor FIX deal with analytical workflows like, in this case, contract parameters.

How?

Where?

This ontology is part of xqo, (official github repository).

The project's canonical home is http://schema.ga-group.nl/xqo/sp/.
